      How it works

      Why not just join them with ^OR? Because in an encoded query ^OR only applies to the condition right before it. a^b^ORc^d means a AND (b OR c) AND d, so joining two queries that way quietly changes what they match.

      The operator that ORs whole queries together is ^NQ (new query). The merger splits each input into its ^NQ blocks, puts all the blocks one after another, drops exact duplicates, and moves any ORDERBY/GROUPBY clauses to the end. If both queries sort on the same field, Query A's sort wins.

      You can paste plain queries, URL-encoded ones (%5E), or a whole list URL with sysparm_query=. A trailing ^EQ is removed. Escaped carets (^^) inside values are kept as they are.

      Everything runs in your browser. Nothing is sent anywhere.
